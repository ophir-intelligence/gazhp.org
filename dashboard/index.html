Record a payment

For payments that don't come through an online export — mobile money, bank transfer, Zelle, cash, checks. Match the donor's reference code (e.g. GAZHP-D-7KQ2M) from their "I've paid" email.

Import data

Upload payment exports (CSV)

Download a CSV from each provider and drop it here. Columns are detected automatically; duplicates are skipped, and failed/refunded payments are ignored.

  • Donorbox: Donations → Export → CSV
  • Stripe: Payments → Export → CSV
  • PayPal: Activity → Statements → Activity download → CSV
  • Flutterwave: Transactions → Export → CSV
  • Any spreadsheet with the columns listed in PAYMENTS-SETUP.md

Where your data lives

Imported and recorded payments are saved only in this browser on this computer — never on the public website. Download a backup regularly and restore it on another computer if needed.

Setup checklist

Everything here is read from js/payments-config.js. Fill in a gateway's details, set enabled: true, and it appears on /donate/ and /join/ automatically.

Change the dashboard passcode

Type a new passcode, then copy the hash into dashboard.passcodeHash in the config file.
